## Release pull request review

<!-- The owner reviews the release pull request with this list before merging it; merging is the decision to publish (references/releases.md, RL-3). -->

- [ ] The proposed version matches the changes: before 1.0, a breaking change or a `feat` bumps the minor version, `fix` and `perf` bump the patch version (RL-1).
- [ ] The release notes are readable, grouped by type with each entry's scope in bold, and contain no AI authorship trailers, AI tool names, secrets or personal data (RL-2, PV-1).
- [ ] Every required check is green on the release pull request.
- [ ] The files generated by `make release-prepare` are present in the pull request (for example the API changelog of this version) (RL-10).
- [ ] No pending security fix or advisory needs to be in this release first (CD-3).
