# Acme Queue: equivalencia con n8n

n8n no tiene un nodo para Acme Queue, así que ningún flujo importado se asigna a este conector. Cuando un servicio tiene un nodo de n8n, se enumera aquí con todas sus diferencias, como en la plantilla declarativa (DC-5).
