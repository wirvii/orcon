# Documentation

Status: Accepted

This file covers the generated connector pages, the hand-written connection guide and the n8n equivalence page. Rule IDs (`DC-…`) are stable. Precedence is in `kinds.md`.

## Rules

- **DC-1** One page per connector, generated by `orcon connector docs` in English and Spanish; never edit generated pages.
- **DC-2** Fixed sections: Overview; Seal and proof levels; Connection; Required scopes and permissions; Network domains; Operations (parameters table, example input and output, repeat safety); Triggers; Rate limits; n8n equivalence; Live-tested; Changelog.
- **DC-3** Every operation has an example from a cassette marked `example: true`.
- **DC-4** `docs/connection-guide.en.md` and `.es.md` are hand-written from `assets/templates/connection-guide/` with its fixed headings: where to create the key or app, which scopes to tick, which redirect URL to enter, how to test.
- **DC-5** `docs/n8n-equivalence.{en,es}.md` names the n8n node it replaces and every difference (missing operations, renamed parameters, different defaults, safety differences); never copies n8n text or images.
- **DC-6** Admission fails if a guide is missing or an operation has no example.
- **DC-7** Pages of connectors for AI model providers are generated under `docs/reference/connectors/ai/` (English) and `docs/reference/connectors/ai/es/` (Spanish), the only documentation path approved for naming those providers; the general index links to `ai/README.md` without naming them.
