# Tables that are immutable after insert (integrity.md IN-11): no updated_at, no
# UPDATE or DELETE privilege for orcon_application; rows leave only through
# retention. Format: <table>  # reason
flow_version  # a published version never changes
flow_snapshot  # content-addressed snapshot of a flow document
call_edge  # derived call graph of a published version
variable_change  # history of variable writes
nondeterminism_record  # recorded results used for replay
execution_event  # ordered event stream of an execution
schema_migration  # one row per applied migration, written once by the migration runner (orcon_owner); never updated or deleted (ADR-0015 §4, MG-4)
trigger_event  # append-only stream of trigger events, kept 30 days (ADR-0020 section 7)
