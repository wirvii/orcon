# The checked definition of an abbreviation (naming rule NM-3, naming.md). A
# token of a database or query name that appears here is rejected. Single
# source of the decision: tools/dbcheck and dbrules both read this file.
#
# Format, one entry per line, in alphabetical order:
#   <token>  # <full word(s)>
# The token matches ^[a-z][a-z0-9]*$ and must not appear in
# allowed_acronyms.txt. Adding a token tightens the rule and needs only
# ordinary review; a reviewer who finds an abbreviation the checker missed adds
# it here in the same change.
